# Aeloon 超前部分实现指南 · 深色模式

> 适用对象：本「Agent 续写项目」（上游开发仓库）的后续迭代 Agent。
> 维护者备注：Aeloon-Pro 仓库的 `novel_web/` 是本项目的 vendored 快照。Aeloon 侧常会先行实现一些「超前」能力，本目录记录这些差异 + 上游对齐方法，避免日后 vendoring 出现实现分叉。

---

## 背景：为什么要做这个

Aeloon-Pro 的前端可切换浅色/深色，但点进「小说续写」（= 本项目，以 iframe 嵌入）后只有浅色，体验割裂。Aeloon 侧已于 **2026-06-20** 先行落地「**目标 1：深色模式 + 进入时跟随 Aeloon 主题**」。本项目目前仍是**纯浅色**，需照此跟进，关键是**色系与机制两边一致**——否则用户在 Aeloon 内嵌的续写页 vs 独立访问续写页会看到两套深色。

只同步**明暗（light/dark）**，不碰强调色——本项目保留自己的「纸墨」品牌色（墨绿 `--jade` / 琥珀 `--amber`），只新增一套深色取值。

---

## 一、核心机制（两边必须一致）

深色通过 `<html data-theme="dark">` 驱动。本项目 CSS 已**全部走 `:root` 变量**，所以只需加一组 `html[data-theme="dark"]` 覆盖块 + 一段 FOUC 脚本，无需改任何结构。

- **在 Aeloon 内（iframe 嵌入）**：主 webui 切深色 → `/novel` iframe 壳读 `localStorage["aeloon:themeMode"]`、解析 `system` → 拼 `?theme=dark` 传进 iframe（本项目页面）→ 页面 `<head>` 的 FOUC 脚本据 query 设 `data-theme`。壳与续写页**跨源**，query 是唯一可靠通道。
- **本项目独立运行（直接访问 `:8765`）**：没有 Aeloon 壳传 query，FOUC 脚本**回退跟随系统** `prefers-color-scheme`。想要手动切换见 [四、可选增强](#四可选增强本项目独立运行的手动切换)。

```
Aeloon 主 webui ──localStorage["aeloon:themeMode"]──▶ /novel 壳 ──?theme=dark──▶ 本项目页面(<head> FOUC) ──▶ html[data-theme="dark"] 深色 CSS
本项目独立访问 :8765  ──(无 query)──▶ FOUC 回退 prefers-color-scheme ──▶ 同一套深色 CSS
```

---

## 二、三处改动（行号与本项目一致，可直接照搬）

本项目 `src/web/` 与 Aeloon `novel_web/src/web/` **同源、行号对齐**（已核对：`_BASE_TPL` 42 行、stylesheet 50 行、`--bg-paper` 86 行均一致）。下面锚点对本项目直接适用。

### 改动 1 · `src/web/templates.py` — `_BASE_TPL` 的 `<head>` 加 FOUC 防闪脚本

在 `<link rel="stylesheet" href="/static/app.css">`（约第 50 行）**之前**插入：

```html
<script>
// 据 ?theme= (Aeloon 壳传入) 先给 <html> 定明暗,避免深色页面闪白;
// 直接访问(无 query)时回退跟随系统。脚本刻意不含美元符,避开 Template 占位。
(function () {
  try {
    var m = location.search.match(/[?&]theme=(dark|light)/);
    var t = m ? m[1] : (window.matchMedia("(prefers-color-scheme: dark)").matches ? "dark" : "light");
    document.documentElement.setAttribute("data-theme", t);
  } catch (e) {}
})();
</script>
```

> **⚠️ 致命坑（务必看）**：`_BASE_TPL` 是 `string.Template`，渲染走 `.substitute()`。脚本里**任何裸 `$` 字符都会被当成占位符** → `ValueError: Invalid placeholder` → **所有页面 500**。
> 实测踩过：连在中文注释里写「本段不含 `$`」的那个 `$` 都会触发。**保持这段脚本纯静态、零 `$`**（上面这版已规避）。若将来要写带 `$` 的 JS，必须把每个 `$` 转义成 `$$`。
> 对比：CSS 在 `CSS_BODY`（普通三引号串）里无此限；Aeloon 的壳 `novel_proxy._shell_html` 是 f-string（`{`/`}` 要写 `{{`/`}}`）——不同字符串载体，转义规则各异。

### 改动 2 · `src/web/static.py` — `CSS_BODY` 的 `:root` 后加深色覆盖块

在 `:root { ... }`（约第 147 行 `}`）**之后**插入。**色值逐一照抄下面这段**——这是「色系一致」的关键：

```css
/* ---------- dark theme ----------
 * 经 <html data-theme="dark"> 切换:Aeloon 壳据其主题、或直接访问时据 ?theme= 注入。
 * 只覆盖颜色 token(间距/圆角/字体不变);暖深棕褐底 + 米白字,延续纸墨气质。
 * badge/alert 用 "strong/强调色文字 + *-soft 软底",故 soft 取暗调、强调色提亮以保对比。 */
html[data-theme="dark"] {
  /* paper / ink */
  --bg-paper: #1C1916;
  --bg-card: #252019;
  --bg-sunken: #15120F;
  --bg-overlay: rgba(0, 0, 0, .6);
  --ink-1: #ECE3D4;
  --ink-2: #B7AC9C;
  --ink-3: #857A6B;
  --ink-inverse: #1C1916;

  /* brand accents */
  --jade: #6FA98E;
  --jade-soft: #23332B;
  --jade-strong: #8FC4A9;
  --amber: #D98F50;
  --amber-soft: #3A2A18;
  --amber-strong: #E8A766;
  --sienna: #D08266;
  --sienna-soft: #3A211A;
  --gold: #D2AE63;
  --gold-soft: #352B16;

  /* lines & shadows */
  --rule: #332D26;
  --rule-strong: #473F35;
  --shadow-card: 0 1px 0 rgba(0, 0, 0, .4);
}

/* skeleton 高光中段是硬编码浅米(#EFE7D6),深色下会刺眼,单独压暗。 */
html[data-theme="dark"] .skeleton {
  background: linear-gradient(90deg, var(--bg-sunken) 0%, #2E2820 50%, var(--bg-sunken) 100%);
}
```

> `.skeleton`（约第 520 行）的渐变中段是**唯一硬编码的浅色 `#EFE7D6`**，深色下会发亮刺眼，所以单独压暗。其余颜色都走变量，重定义 `:root` token 即全局生效。

### 改动 3 · `novel_proxy.py` 壳 —— **本项目不需要**

这是 Aeloon **网关侧**的 iframe 壳（读 localStorage、解析 system、拼 `?theme=`、回写）。本项目里没有这个文件，独立运行靠改动 1 的 FOUC 回退跟随系统即可，无需移植。

## 三、深色色系 token 表（必须逐值一致）

| 变量 | 浅色（现状，勿改） | 深色（新增） | 用途 |
|---|---|---|---|
| `--bg-paper` | `#FBF7F0` | `#1C1916` | 页面底 |
| `--bg-card` | `#FFFEFB` | `#252019` | 卡片底（比 paper 略亮） |
| `--bg-sunken` | `#F4EEE2` | `#15120F` | 凹陷/输入底（比 paper 更深） |
| `--bg-overlay` | `rgba(42,37,32,.45)` | `rgba(0,0,0,.6)` | 模态遮罩 |
| `--ink-1` | `#2A2520` | `#ECE3D4` | 主文字 |
| `--ink-2` | `#5C544A` | `#B7AC9C` | 次文字 |
| `--ink-3` | `#9B9285` | `#857A6B` | 弱文字/占位 |
| `--ink-inverse` | `#FBF7F0` | `#1C1916` | 反色（当前未被引用，跟随翻转） |
| `--jade` | `#3F6B5A` | `#6FA98E` | 翡翠主品牌 |
| `--jade-soft` | `#E6EFE9` | `#23332B` | 翡翠软底（badge/alert 底） |
| `--jade-strong` | `#2E5343` | `#8FC4A9` | 翡翠强（软底上的文字） |
| `--amber` | `#C97B3D` | `#D98F50` | 琥珀 CTA |
| `--amber-soft` | `#F8E7D3` | `#3A2A18` | 琥珀软底 |
| `--amber-strong` | `#A35F27` | `#E8A766` | 琥珀强 |
| `--sienna` | `#A8533D` | `#D08266` | 赭红（错误/拒绝） |
| `--sienna-soft` | `#F4DCD2` | `#3A211A` | 赭红软底 |
| `--gold` | `#B89249` | `#D2AE63` | 金（警告） |
| `--gold-soft` | `#F4E7C7` | `#352B16` | 金软底 |
| `--rule` | `#E7DFD2` | `#332D26` | 分隔线 |
| `--rule-strong` | `#D4C9B4` | `#473F35` | 强分隔线 |
| `--shadow-card` | `0 1px 0 var(--rule)` | `0 1px 0 rgba(0,0,0,.4)` | 卡片阴影 |

**设计原则**：底色三档保持「越上层越亮」（sunken < paper < card）；强调色整体提亮约 15–25% 以满足深底 AA 对比；`*-soft` 软底改为对应色相的暗调，保证 badge/alert 的「色块底 + 强色字」组合在深色下依旧成立（本项目 `static.py` 约 379–384 行的 `.badge.*` 正是这种用法）。

## 四、可选增强：本项目独立运行的手动切换

目标 1 只做「跟随」（Aeloon 传入 / 系统偏好）。Aeloon 侧把「在续写页里手动切主题、并反向影响 Aeloon」列为**目标 2，尚未实现**。若本项目独立运行时想让用户手动切深浅：

1. 顶栏 `_topbar_actions()`（约 187–193 行）最前面加一个按钮：
   ```python
   '<button type="button" class="btn btn-icon" data-theme-toggle aria-label="切换深色/浅色">🌙</button>'
   ```
2. 切换 JS 加在 `JS_DASHBOARD` 的 `initShellControls()` 内（复用其 `querySelector + addEventListener` 模式）：
   ```js
   var b = document.querySelector("[data-theme-toggle]");
   if (b) b.addEventListener("click", function () {
     var t = document.documentElement.getAttribute("data-theme") === "dark" ? "light" : "dark";
     document.documentElement.setAttribute("data-theme", t);
     b.textContent = t === "dark" ? "☀" : "🌙";
     try { localStorage.setItem("aeloon:themeMode", t); } catch (e) {}
   });
   ```
3. FOUC 脚本回退也读 localStorage（让刷新记住手动选择）：把改动 1 里的回退分支改为
   ```js
   var t = m ? m[1] : (localStorage.getItem("aeloon:themeMode") || (window.matchMedia("(prefers-color-scheme: dark)").matches ? "dark" : "light"));
   if (t !== "dark" && t !== "light") t = "light";
   ```

> **统一约定**：localStorage 的 key 用 **`"aeloon:themeMode"`**（与 Aeloon 主 webui 同一个 key、同一套 `"light"|"dark"|"system"` 取值）。即使两边代码不互通，也保持「概念一致」，便于将来对齐目标 2（Aeloon 续写页切主题反向影响主 webui）。

## 六、一致性约定（重要）

- **色系 token 是 single source of truth**：上表的深色取值两边必须**逐值相同**。要调色，先在两处同步改，再分别验证。
- Aeloon `novel_web/` 是本项目的 vendored 快照；本指南让上游补齐这块「超前实现」，**避免下次 vendoring 时深色实现分叉/冲突**。
- 本项目独立运行靠 FOUC 回退（跟随系统）即可用上深色；Aeloon 内嵌靠壳传 `?theme=`。两条路径共用同一套 `html[data-theme="dark"]` CSS。
- 对应 Aeloon 提交：见 Aeloon-Pro 仓库 `dev/ui` 分支「小说续写深色模式（目标 1）」相关 PR。
